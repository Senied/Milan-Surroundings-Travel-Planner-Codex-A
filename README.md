## Open locally

```bash
cd milan-surroundings-modular-travel-planner-site
python -m http.server 18903 --bind 127.0.0.1
```

Then visit [http://127.0.0.1:18903/](http://127.0.0.1:18903/).

## Site structure

- `guide/` contains the canonical v1.1 interactive content and its friendly-named, byte-identical PDF.
- `previous/` keeps the earlier edition available.
- `releases/` preserves the exact v1.1 HTML, PDF, ZIP, QA evidence, manifests and checksums linked from the public site.
